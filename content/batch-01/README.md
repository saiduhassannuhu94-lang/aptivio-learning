## Status definitions

- **Not started:** no course content package exists.
- **Draft authored:** package exists, but has not passed all review gates.
- **Validated:** structural/content checks and technical review passed.
- **In academic review:** submitted to an authorised reviewer.
- **Approved:** a real reviewer decision has been recorded.
- **Published:** the approved version is visible in the learner catalogue.

Do not count draft, validated or in-review packages as published courses. Never fill review fields with placeholder identities or dates.
